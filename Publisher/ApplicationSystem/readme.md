# ApplicationSystem Publisher

## 运行流程


Version 1.0.0
1. 将/dev/config.ini中的"robot_control_exe/robot_control_config"更改为自己的机器人工程目录
2. joystick_file也更改为自己电脑默认首个手柄接入的名称(默认均为js0)
3. 给application_systemd.*文件执行权限
4. bash start-application_systemd.sh  运行程序进行APP控制
